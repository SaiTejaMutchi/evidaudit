# Security Policy

## Scope and Responsible Use
**EvidAudit** is a diagnostic evaluation toolkit designed to detect concealed semantic corruption, temporal-binding failures, and policy-transition vulnerabilities in AI authorization gates and neuro-symbolic systems.

- All included authorization policies are synthetic closed-world test specifications or publicly available benchmark evaluations (`FOLIO`, `LINC`, public FAR sections).
- Never rely solely on unverified LLM date arithmetic or flattened statutory extractions in high-stakes production authorization gates without deterministic fail-closed checks and human review.

## Reporting a Vulnerability
If you discover a security issue in `evidaudit` (such as a fail-open bug in `checker.py`), please open a private security advisory on GitHub or contact the maintainers before public disclosure.
