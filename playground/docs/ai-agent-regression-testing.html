AI Agent Regression Testing

Learn how to regression test AI agents and LLM decision pipelines for concealed semantic errors and policy-transition failures without API keys.

Outcome-only accuracy hides semantic errors when an active override or fallback rule masks a wrong intermediate fact. EvidAudit runs deterministic regression tests over structured agent propositions and policy transitions.

Working Example

from evidaudit import Auditor

auditor = Auditor()
res = auditor.evaluate(
    propositions={
        "prerequisites": [{"rule_id": "req_kyc", "prerequisite_satisfied": "TRUE", "evidence_ids": ["E1"]}],
        "prohibitions": [{"rule_id": "prohib_sanction", "prohibition_applies": "FALSE", "evidence_ids": ["E2"]}],
        "overrides": [{"rule_id": "ov_waiver", "targets_prohibition": "prohib_sanction", "override_valid": "TRUE", "authority_rank": 3, "evidence_ids": ["E3"]}],
    },
    evidence={
        "packet_ids": {"E1", "E2", "E3"},
        "reference_decision": "ALLOW",
        "reference_propositions": {"prerequisites": {"req_kyc": "TRUE"}, "prohibitions": {"prohib_sanction": "TRUE"}, "overrides": {"ov_waiver": "TRUE"}},
    },
)
print(res.concealed_corruption, res.semantic_errors)
