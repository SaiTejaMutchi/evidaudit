AI Agent Authorization Testing

Test AI authorization gates for fail-closed grounding, exact rule-ID override matching, and three-valued abstention semantics.

EvidAudit enforces fail-closed deterministic checking (v2-strict): policy-only citations (such as P1) are rejected, unknown prohibitions abstain rather than defaulting to false, and overrides require exact rule-ID matching and rank >= 2.

Working Example

from evidaudit import evaluate_extraction

res = evaluate_extraction(
    {"prerequisites": [{"rule_id": "req1", "prerequisite_satisfied": "TRUE", "evidence_ids": ["P1"]}], "prohibitions": [], "overrides": []},
    valid_packet_ids={"P1", "E1"},
)
print(res.decision, res.reasons)  # ABSTAIN ['ungrounded_prereq_true:req1']
