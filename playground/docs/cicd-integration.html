CI/CD & Pytest Integration

Run deterministic AI agent policy regression tests in pytest and GitHub Actions without API keys or LLM spend.

EvidAudit executes declarative YAML test cases and Python assertions deterministically with zero external API keys, making it suitable for pull-request gates in GitHub Actions and pytest.

Working Example

# Run declarative YAML regression tests in CI (zero API keys)
# evidaudit test examples/payment_expiry.yaml --json

from pathlib import Path
from evidaudit.yaml_runner import run_yaml_test_case

res = run_yaml_test_case(Path("examples/payment_expiry.yaml"))
assert res.passed and res.concealed_corruption
