Policy Transition Testing

Test whether AI agent decisions remain safe when overrides are revoked or time windows expire, and detect replay-vs-regeneration gaps.

Revoking an executive waiver or advancing an evaluation date past expiry exposes concealed extraction faults. EvidAudit compares frozen-extraction replay against fresh regeneration and verifies single-proposition repairs.

Working Example

from evidaudit import Auditor

auditor = Auditor()
exp = auditor.test_override_revocation(
    propositions={
        "prerequisites": [{"rule_id": "req1", "prerequisite_satisfied": "TRUE", "evidence_ids": ["E1"]}],
        "prohibitions": [{"rule_id": "prohib1", "prohibition_applies": "FALSE", "evidence_ids": ["E2"]}],
        "overrides": [{"rule_id": "ov1", "targets_prohibition": "prohib1", "override_valid": "TRUE", "authority_rank": 3, "evidence_ids": ["E3"]}],
    },
    target_prohibition="prohib1",
    prohibition_id="prohib1",
    packet_ids={"E1", "E2", "E3"},
)
print(exp.post_transition_decision, exp.repaired_decision)  # ALLOW, BLOCK
