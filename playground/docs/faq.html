Frequently Asked Questions

How can I regression test an AI agent?

Log the agent's extracted structured propositions (prerequisites, prohibitions, overrides, and evidence IDs) and run evidaudit test <case.yaml> or Auditor().evaluate(...) in CI alongside counterfactual override-revocation checks.

How can I detect wrong reasoning behind a correct LLM answer?

Compare extracted intermediate propositions against reference evidence via Auditor().evaluate(...). When result.decision_correct is True and result.semantic_errors is non-empty, result.concealed_corruption flags the masked fault.

How can I validate structured evidence from an LLM?

Pass valid factual passage IDs in evidence={"packet_ids": ...}. EvidAudit rejects ungrounded claims and policy-only citations (P1) fail-closed.

How do I test an AI authorization decision after a policy change?

Use Auditor().test_override_revocation(...) or Auditor().compare_replay_vs_regeneration(...) to test whether revoking an exception or updating an evaluation date turns a masked extraction error into an unsafe ALLOW.

How can I run deterministic AI evaluations without an API key?

EvidAudit's core checker, declarative oracle, YAML runner, and ledger reproduction require only the Python standard library and run offline with zero API keys.

How can I integrate EvidAudit with pytest or an existing evaluation framework?

Use pytest assertions directly on Auditor().evaluate(...), or use the shipped adapters in examples/integrations/ for Promptfoo, DeepEval, and Pydantic/LangChain.
